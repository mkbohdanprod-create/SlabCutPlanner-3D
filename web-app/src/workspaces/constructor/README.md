# workspaces/constructor — Viyar Stone Конструктор

Дочка технолога. Відповідає на «як це зробити». Заведено 03.09.2026
рішенням власника: **Конструктор — перший, Архітектура — паралельно.**

## Що тут живе

Сьогодні (v0) — той самий `App` із правами технолога без ПІНа
(`shell/capabilities.ts` → `constructor.grants`): метал і шаблони
каркасів, «Послуги для виробництва», припуски, імпорт DXF і SketchUp,
старий редактор деталей, паспорт деталі, 3D-прев'ю.

Далі сюди переїжджають (з `01_МЕЙН/ЩО_ВИНОСИМО_З_VS3D.md`, §2.2) і
приходять з обучалочки (`06_ОБУЧАЛОЧКА/ОБУЧАЛОЧКА.md` §0, §4.1;
`12_ВИРОБНИЦТВО_І_МЕС/00_ТЗ_ПАСПОРТ_ВИРОБНИЦТВА.md`) — **кожне своєю
підтекою, окремим модулем (інваріант 2.48):**

```
constructor/
  survey/        ← замір поруч із проєктом, «лист розбіжностей» (крок 2 візії)
  metal/         ← метал: ланцюги, шаблони, супутнє замовлення (переїзд із components/ui)
  plywood/       ← калькулятор підкладу (ПРАВИЛА_ФАНЕРА)
  production/    ← паспорт виробництва, послуги на ділянках, JSON для MES
  documents/     ← ТЗ конструктору, ТЗ монтажнику, бланк заміру
```

## Правила

- Математика — тільки в ядрі (`engines/`, `domain/`). Тут — екрани,
  документи й сценарії технолога. Треба порахувати — додаєш у ядро.
- Спільні цеглини (редактор виробу, 3D, таблиця сторін) беруться зі
  спільного шару, а не копіюються. Відмінності — через `useCan(...)`.
- Грошей тут немає: ціни лишаються у VS3D (візія Конструктора §7).
- Вхід: `?workspace=constructor`.
