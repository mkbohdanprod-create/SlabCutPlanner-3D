# workspaces/architecture — Viyar Stone Архітектор

Третя програма на тому самому ядрі, що VS3D і Конструктор (рішення
власника 06.09.2026: «не окреме ядро, а відгалуження»). Відповідає на
«скільки коштує облицювати об'єкт»: підлоги, стіни, пано — розкладками;
рецепції, сходи, портали — виробами, як у VS3D. Усе в одному проєкті,
одна пачка → розкрій, квадратури, відомість, комерційна.

## Перша версія (06.09.2026)

```
architecture/
  store.ts                 ← стан сеансу: інструмент плану, вибір, меню розкладки
  useArchitecture.ts       ← доступ до project.architecture (updateProject)
  ArchitectureSidebar.tsx  ← ліва колонка: «Додати виріб» + «Створити розкладку», списки
  plan/PlanEditor.tsx      ← ПЛАН: PDF/картинка-підложка, масштаб (2 кліки + мм),
                             обведення підлог, отвори, стіни з ребер; pdf.js ліниво
  layouts/LayoutControls   ← ручки розкладки (патерн, формат, шов, старт, матеріал)
  layouts/LayoutPreview    ← картинка: цілі світлі, підрізи штрихом, бордюр
  layouts/LayoutEditor     ← РОЗКЛАДКА: головне вікно з живими числами, «У розкрій»
  layouts/AddLayoutWorkspace ← окреме меню створення (на основі меню виробу)
  documents/BoqPanel.tsx   ← ВІДОМІСТЬ обсягів по групах, CSV, друк
```

Ядро (без React, `coreBoundary.test.ts`):

- `domain/architecture.ts` — модель: `PlanUnderlay`, `Surface`
  (floor/wall + openings), `TileLayout`, `ArchitectureNorms`
  (`DEFAULT_ARCH_NORMS` — УМОВНО), матеріали, формати, `wallFromEdge`.
- `engines/tileLayout.ts` — генератори патернів (пряма, розбіжка,
  діагональ, ялинка, периметр + центр), обрізання Сазерленда–Годжмана,
  статистика (цілі/підрізи/листи/шви/різ/вага/клей/фуга/монтаж/машини),
  `boqForLayout`, `computeArchitecture`. Тести —
  `engines/__tests__/tileLayout.test.ts` (16).

Підключення до ядра: `PaneView` `'plan' | 'layout' | 'boq'`,
`ARCHITECTURE_VIEWS`, `architectureMode` в `useUIStore`
(взаємовиключний із `constructorMode`), вкладки в `WorkspaceTabs`
(«2D Підбір» і «Приміщення» в цьому режимі сховані — план їх заміняє;
конструкторські вкладки не показуються), ліниві панелі в
`WorkspacePane`, `Project.architecture?` у `domain/types.ts`, картка
«Архітектура» в Студії, мобільна навігація План/Розкладка/Розкрій/Відомість.

## Що ще не зроблено (наступні кроки)

- Правила побудови розкладок від власника (точка старту, набір
  патернів, розбіжка ½/⅓, шви, мінімальний підріз/симетрія) — зараз
  дефолти першої версії, `04_ВІЗІЯ_АРХІТЕКТУРИ/ПРАВИЛА_РОЗКЛАДОК.md`.
- Розкладки в 3D Підборі (стіни й підлога зі сцени); монтажна схема з
  нумерацією плиток; ціни в «Прорахунку» для рядків відомості.
- Отвори на стінах (двері/вікна) — зараз лише на підлозі; довільні
  отвори (не прямокутник).
- Вхід: картка в Студії або `?workspace=architecture`.
