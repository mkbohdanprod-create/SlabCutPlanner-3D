# workspaces/architecture — Viyar Stone Архітектура

Дочка для об'єктів (тендери, облицювання). Відповідає на «скільки коштує
облицювати об'єкт». Каркас заведено 03.09.2026 під **паралельну** роботу
з Конструктором — щоб у цієї роботи з першого дня була своя тека, а не
ще один режим у VS3D.

## Що тут живе

Сьогодні — той самий `App` із «Приміщенням» (права —
`shell/capabilities.ts` → `architecture.grants`). Власне Архітектура —
за `04_ВІЗІЯ_АРХІТЕКТУРИ/ВІЗІЯ_АРХІТЕКТУРА.md`, фазами:

```
architecture/
  room/          ← Приміщення: контур, отвори, колони (є база в domain/room.ts)
  surfaces/      ← Поверхня (підлога/стіна) зі своєю розкладкою
  layouts/       ← генератори розкладок: пряма, ялинка, діагональ, периметр+центр
  takeoff/       ← математика об'єкта: листи, шви, клей, вага → машини, монтаж
  documents/     ← КП + BOQ + монтажна схема з одних даних
```

## Правила

- Ті самі, що в Конструктора: математика — в ядрі, копій спільних
  цеглин немає, відмінності через `useCan(...)`.
- Розкрій листів 3200×1600, підбір текстури, конструктор виробів для
  рецепцій/камінів, сцена, PDF — беруться з ядра і спільного шару як є.
- Фаза 0 за візією — без коду: 2–3 реальні тендери руками, щоб зібрати
  правила й економіку. Код — з фази 1.
- Вхід: `?workspace=architecture`.
